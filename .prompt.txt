LUREAD ANDROID. MASTER ENGINEERING PROMPT

MISI UTAMA

Bangun aplikasi Android native bernama Luread, sebuah perpustakaan digital pribadi dan ebook reader yang sangat lengkap, gratis, tanpa akun, sangat customizable, cepat, stabil, dan memiliki kualitas desain setara aplikasi komersial yang matang.

Luread menggunakan Gutendex sebagai sumber utama katalog ebook gratis dari Project Gutenberg. Aplikasi juga harus mendukung pembacaan file lokal, manajemen perpustakaan, anotasi, pencarian, bantuan bahasa, statistik membaca, personalisasi tampilan, dan fitur produktivitas membaca.

Kamu bekerja sebagai senior Android engineer, software architect, UI/UX researcher, performance engineer, accessibility specialist, dan QA engineer.

Tugasmu bukan sekadar membuat desain atau prototype. Tugasmu adalah membangun source code lengkap yang dapat dikompilasi menjadi APK Android melalui GitHub Actions.

Target kualitas:

- Sangat kaya fitur.
- Semua fitur inti benar-benar berfungsi.
- Tampilan premium, konsisten, dan tidak terlihat generik.
- Animasi halus tetapi tidak mengganggu membaca.
- Kustomisasi mendalam dan benar-benar persisten.
- Arsitektur modular yang mudah dikembangkan.
- Bisa digunakan tanpa login.
- Tidak memerlukan API key berbayar.
- Bisa membaca buku lokal tanpa internet.
- Memiliki pengujian dan dokumentasi yang dapat diverifikasi.

Jangan mengurangi fitur hanya karena jumlahnya banyak. Namun, jangan pula membuat fitur palsu hanya agar daftar fitur terlihat panjang. Implementasikan secara bertahap, pertahankan project tetap buildable, dan verifikasi setiap bagian.

2. AUDIT GUTENDEX DAN JSON ASLI

Endpoint utama:
"https://gutendex.com/books"

Repository:
"https://github.com/garethbjohnson/gutendex"

Uji endpoint secara langsung sebelum membuat data model.

Contoh pengujian:

- "GET /books"
- "GET /books?search=sherlock"
- "GET /books?languages=en"
- "GET /books?topic=children"
- "GET /books?ids=1342"
- "GET /books?mime_type=text%2Fhtml"

Periksa respons JSON aktual, kode HTTP, header relevan, pagination, variasi field, format file, dan kondisi error.

Audit struktur katalog yang benar-benar ditemukan, termasuk:

- "count"
- "next"
- "previous"
- "results"

Audit field buku yang tersedia, termasuk:

- "id"
- "title"
- "authors"
- "summaries"
- "editors"
- "translators"
- "subjects"
- "bookshelves"
- "languages"
- "copyright"
- "media_type"
- "formats"
- "download_count"

Periksa struktur objek person dan kemungkinan field kosong, null, atau array kosong.

Periksa URL format buku yang nyata. Jangan menganggap setiap buku mempunyai EPUB, HTML, TXT, atau cover. Jangan membangun URL download berdasarkan ID tanpa bukti.

Dokumentasikan:

- Endpoint yang diuji.
- Parameter yang digunakan.
- Tanggal pengujian.
- Status HTTP.
- Struktur JSON yang teramati.
- Variasi data.
- Format yang benar-benar tersedia.
- Kegagalan request.
- Batasan yang ditemukan.

Jangan mengunduh seluruh katalog secara massal. Gunakan pagination sesuai kebutuhan dan hormati layanan sumber.

3. LOGO RESMI LUREAD

Logo resmi akan dibuat sendiri oleh pemilik project pada lokasi:

"image/logo.png"

File tersebut mungkin belum tersedia saat pengerjaan dimulai.

Aturan mutlak:

1. Jangan membuat logo sendiri.
2. Jangan menggunakan logo generik sebagai pengganti.
3. Jangan mengarang isi file logo.
4. Jangan membuat placeholder palsu dengan nama "logo.png".
5. Periksa keberadaan file sebelum integrasi.
6. Jika belum tersedia, lanjutkan seluruh pengembangan tanpa menghambat build.
7. Siapkan mekanisme integrasi otomatis yang tervalidasi ketika file tersedia.
8. Jangan memodifikasi file logo sumber secara otomatis.
9. Catat status integrasi logo di dokumentasi.
10. Gunakan logo konsisten hanya pada tempat yang sesuai, seperti splash screen dan halaman About.

Path tersebut berada di root project. File tidak dapat digunakan langsung sebagai Android resource hanya karena file tersebut ada di root.

Jika tersedia, salin melalui task Gradle atau skrip build yang aman ke:
"app/src/main/res/drawable-nodpi/"

Pastikan task memeriksa keberadaan dan validitas PNG. Jika file tidak tersedia, task harus melewatinya tanpa menggagalkan build.

Jangan membuat ikon aplikasi palsu. Jika belum ada logo, gunakan konfigurasi ikon sementara yang tidak mengklaim sebagai logo resmi atau tunda integrasi ikon branding sesuai kebutuhan teknis.

26. LAPORAN AKHIR

Setelah seluruh pekerjaan selesai, berikan laporan yang mencakup:
FITUR WAJIB: ANDROID SYSTEM TRANSLATOR INTEGRATION

Luread harus memiliki sistem penerjemahan yang menggunakan penerjemah nyata, bukan terjemahan dummy, hasil buatan, atau simulasi.

1. Penerjemahan di dalam ebook reader

Ketika pengguna memilih kata, kalimat, atau paragraf dalam EPUB, TXT, atau format lain yang mendukung seleksi teks:

- Tampilkan menu konteks yang menyediakan opsi Translate.
- Ambil teks yang benar-benar dipilih pengguna.
- Berikan opsi untuk menerjemahkan teks melalui aplikasi penerjemah Android yang kompatibel.
- Pertahankan posisi membaca dan jangan menghilangkan seleksi secara tidak sengaja.
- Sediakan aksi Copy dan Share sebagai alternatif.
- Jika memungkinkan, tampilkan hasil terjemahan dalam panel atau dialog Luread setelah hasil nyata diterima.
- Jangan menganggap PDF mendukung seleksi teks jika implementasi PDF yang digunakan tidak menyediakannya.

2. Gunakan penerjemah sistem yang benar-benar tersedia

Teliti dan implementasikan integrasi Android yang sesuai, termasuk:

- "Intent.ACTION_PROCESS_TEXT".
- "Intent.EXTRA_PROCESS_TEXT".
- "Intent.EXTRA_PROCESS_TEXT_READONLY".
- Pemeriksaan activity yang kompatibel melalui "PackageManager".
- Penanganan hasil dan error berdasarkan kontrak API yang sebenarnya.
- Kompatibilitas Android dan aturan package visibility yang berlaku.

Jangan mengasumsikan bahwa Android menyediakan satu API universal untuk meminta aplikasi penerjemah sistem tertentu. Jangan hardcode nama package Google Translate atau menganggap aplikasi tersebut selalu terpasang.

Tampilkan aksi penerjemahan eksternal hanya ketika handler yang kompatibel benar-benar ditemukan. Jika tidak ada, berikan pesan yang jelas dan opsi Copy atau Share.

3. Penerjemah di luar ebook

Buat halaman khusus bernama Translator yang memungkinkan pengguna:

- Mengetik atau menempelkan teks.
- Memilih bahasa sumber jika didukung.
- Memilih bahasa tujuan.
- Menyalin teks sumber.
- Membuka penerjemah eksternal yang kompatibel.
- Membagikan teks ke aplikasi penerjemah.
- Menangani teks kosong dan kegagalan intent dengan benar.
- Menyalin hasil terjemahan jika hasil nyata tersedia.

Jangan menampilkan hasil terjemahan jika Luread tidak benar-benar menerimanya dari layanan yang digunakan.

4. Penerjemahan native di dalam Luread

Riset apakah integrasi penerjemahan lokal melalui ML Kit Translation cocok sebagai opsi tambahan. Periksa dokumentasi resmi, dukungan bahasa, kebutuhan model, ukuran unduhan, dan ketentuan penggunaan.

Jika dipilih:

- Implementasikan penerjemahan melalui API resmi.
- Kelola unduhan model bahasa.
- Tampilkan status model belum diunduh, sedang diunduh, siap, dan gagal.
- Sediakan pilihan bahasa sumber dan tujuan.
- Jalankan pemrosesan di luar main thread.
- Tangani error dan model yang tidak tersedia.
- Jelaskan kebutuhan koneksi saat model belum tersedia.
- Jangan mengklaim seluruh proses selalu offline sebelum model bahasa benar-benar tersedia secara lokal.
- Jangan menyamakan penerjemah lokal ML Kit dengan penerjemah bawaan sistem Android.
